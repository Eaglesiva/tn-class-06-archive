# இயல் 3.1 — ஆசிய ஜோதி — Quiz

## STEP 2 — Original Textbook MCQ

1. புத்தரின் வரலாற்றைக் கூறும் நூல் எது?
   - அ) ஜீவ ஜோதி
   - ஆ) ஆசிய ஜோதி
   - இ) நவ ஜோதி
   - ஈ) ஜீவன் ஜோதி
   **விடை:** ஆ
   **விளக்கம்:** ‘ஆசிய ஜோதி’ புத்தரின் வரலாற்றைக் கூறும் நூல்.
   **Source:** [2025 பாடநூல் உரை](https://www.scribd.com/document/1074941698/Class-6-Tamil-Tamil-Tamil-Term-3-2025-Edition-www-tntextbooks-in)

2. நேர்மையான வாழ்வை வாழ்பவர் யார்?
   - அ) எல்லா உயிர்களிடத்தும் இரக்கம் கொண்டவர்
   - ஆ) உயிர்களைத் துன்புறுத்துபவர்
   - இ) தம்மை மட்டும் காத்துக்கொள்பவர்
   - ஈ) தம் குடும்பத்தையே எண்ணி வாழ்பவர்
   **விடை:** அ
   **விளக்கம்:** எல்லா உயிர்களிடத்தும் இரக்கம் கொள்வதே நேர்மையான வாழ்வின் அடையாளம்.
   **Source:** [2025 பாடநூல் உரை](https://www.scribd.com/document/1074941698/Class-6-Tamil-Tamil-Tamil-Term-3-2025-Edition-www-tntextbooks-in)

3. ஒருவர் செய்யக் கூடாதது எது?
   - அ) நல்வினை
   - ஆ) தீவினை
   - இ) பிறவினை
   - ஈ) தன்வினை
   **விடை:** ஆ
   **விளக்கம்:** பிற உயிர்களுக்குத் தீங்கு விளைவிக்கும் தீவினையைச் செய்யக்கூடாது.
   **Source:** [2025 பாடநூல் உரை](https://www.scribd.com/document/1074941698/Class-6-Tamil-Tamil-Tamil-Term-3-2025-Edition-www-tntextbooks-in)

4. ‘எளிதாகும்’ என்னும் சொல்லைப் பிரித்து எழுதக் கிடைப்பது எது?
   - அ) எளிது + தாகும்
   - ஆ) எளி + தாகும்
   - இ) எளிது + ஆகும்
   - ஈ) எளிதா + ஆகும்
   **விடை:** இ
   **விளக்கம்:** எளிதாகும் = எளிது + ஆகும்.
   **Source:** [2025 பாடநூல் உரை](https://www.scribd.com/document/1074941698/Class-6-Tamil-Tamil-Tamil-Term-3-2025-Edition-www-tntextbooks-in)

5. ‘பாலையெல்லாம்’ என்னும் சொல்லைப் பிரித்து எழுதக் கிடைப்பது எது?
   - அ) பாலை + யெல்லாம்
   - ஆ) பாலை + எல்லாம்
   - இ) பாலை + எலாம்
   - ஈ) பா + எல்லாம்
   **விடை:** ஆ
   **விளக்கம்:** பாலையெல்லாம் = பாலை + எல்லாம்.
   **Source:** [2025 பாடநூல் உரை](https://www.scribd.com/document/1074941698/Class-6-Tamil-Tamil-Tamil-Term-3-2025-Edition-www-tntextbooks-in)

6. இனிமை + உயிர் என்பதனைச் சேர்த்தெழுதக் கிடைக்கும் சொல் எது?
   - அ) இன்உயிர்
   - ஆ) இனியஉயிர்
   - இ) இன்னுயிர்
   - ஈ) இனிமைஉயிர்
   **விடை:** இ
   **விளக்கம்:** இனிமை + உயிர் புணர்ந்து இன்னுயிர் என அமைகிறது.
   **Source:** [2025 பாடநூல் உரை](https://www.scribd.com/document/1074941698/Class-6-Tamil-Tamil-Tamil-Term-3-2025-Edition-www-tntextbooks-in)

7. மலை + எலாம் என்பதனைச் சேர்த்தெழுதக் கிடைக்கும் சொல் எது?
   - அ) மலை எலாம்
   - ஆ) மலையெலாம்
   - இ) மலையெல்லாம்
   - ஈ) மலைஎல்லாம்
   **விடை:** ஆ
   **விளக்கம்:** மலை + எலாம் புணர்ந்து மலையெலாம் என அமைகிறது.
   **Source:** [2025 பாடநூல் உரை](https://www.scribd.com/document/1074941698/Class-6-Tamil-Tamil-Tamil-Term-3-2025-Edition-www-tntextbooks-in)
