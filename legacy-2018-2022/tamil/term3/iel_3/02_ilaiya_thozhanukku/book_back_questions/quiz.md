# இயல் 3.2 — இளைய தோழனுக்கு — Quiz

## STEP 2 — Original Textbook MCQ

1. உன்னுடன் நீயே ______ கொள்.
   - அ) சேர்ந்து
   - ஆ) பகை
   - இ) கைகுலுக்கிக்
   - ஈ) நட்பு
   **விடை:** இ
   **விளக்கம்:** கவிஞர் தன்னம்பிக்கையுடன் தன்னையே ஊக்கப்படுத்திக் கொள்ள ‘கைகுலுக்கிக் கொள்’ என்கிறார்.
   **Source:** [2025 பாடநூல் உரை](https://www.scribd.com/document/1074941698/Class-6-Tamil-Tamil-Tamil-Term-3-2025-Edition-www-tntextbooks-in)

2. கவலைகள் ______ அல்ல.
   - அ) சுமைகள்
   - ஆ) சுவைகள்
   - இ) துன்பங்கள்
   - ஈ) கைக்குழந்தைகள்
   **விடை:** ஈ
   **விளக்கம்:** ‘கவலைகள் கைக்குழந்தைகள் அல்ல’ என்பது பாடல்வரி.
   **Source:** [2025 பாடநூல் உரை](https://www.scribd.com/document/1074941698/Class-6-Tamil-Tamil-Tamil-Term-3-2025-Edition-www-tntextbooks-in)

3. ‘விழித்தெழும்’ என்னும் சொல்லைப் பிரித்து எழுதக் கிடைப்பது எது?
   - அ) விழி + எழும்
   - ஆ) விழித்து + எழும்
   - இ) விழி + தெழும்
   - ஈ) விழித் + தெழும்
   **விடை:** ஆ
   **விளக்கம்:** விழித்தெழும் = விழித்து + எழும்.
   **Source:** [2025 பாடநூல் உரை](https://www.scribd.com/document/1074941698/Class-6-Tamil-Tamil-Tamil-Term-3-2025-Edition-www-tntextbooks-in)

4. ‘போவதில்லை’ என்னும் சொல்லைப் பிரித்து எழுதக் கிடைப்பது எது?
   - அ) போவது + இல்லை
   - ஆ) போ + இல்லை
   - இ) போவது + தில்லை
   - ஈ) போ + தில்லை
   **விடை:** அ
   **விளக்கம்:** போவதில்லை = போவது + இல்லை. பாடநூலில் இ/ஈ விருப்பங்கள் ஒரேபோல் அச்சிடப்பட்டதால், quiz-இல் ஈ மாற்று வேறுபடுத்தப்பட்டுள்ளது.
   **Source:** [2025 பாடநூல் உரை](https://www.scribd.com/document/1074941698/Class-6-Tamil-Tamil-Tamil-Term-3-2025-Edition-www-tntextbooks-in)

5. ‘படுக்கையாகிறது’ என்னும் சொல்லைப் பிரித்து எழுதக் கிடைப்பது எது?
   - அ) படுக்கை + யாகிறது
   - ஆ) படுக்கையா + ஆகிறது
   - இ) படுக்கையா + கிறது
   - ஈ) படுக்கை + ஆகிறது
   **விடை:** ஈ
   **விளக்கம்:** படுக்கையாகிறது = படுக்கை + ஆகிறது.
   **Source:** [2025 பாடநூல் உரை](https://www.scribd.com/document/1074941698/Class-6-Tamil-Tamil-Tamil-Term-3-2025-Edition-www-tntextbooks-in)

6. தூக்கி + கொண்டு என்பதனைச் சேர்த்தெழுதக் கிடைக்கும் சொல் எது?
   - அ) தூக்கிகொண்டு
   - ஆ) தூக்குக்கொண்டு
   - இ) தூக்கிக்கொண்டு
   - ஈ) தூக்குகொண்டு
   **விடை:** இ
   **விளக்கம்:** தூக்கி + கொண்டு புணர்ந்து தூக்கிக்கொண்டு என அமைகிறது.
   **Source:** [2025 பாடநூல் உரை](https://www.scribd.com/document/1074941698/Class-6-Tamil-Tamil-Tamil-Term-3-2025-Edition-www-tntextbooks-in)

7. விழித்து + எழும் என்பதனைச் சேர்த்தெழுதக் கிடைக்கும் சொல் எது?
   - அ) விழியெழும்
   - ஆ) விழித்தெழும்
   - இ) விழித்தழும்
   - ஈ) விழித்துஎழும்
   **விடை:** ஆ
   **விளக்கம்:** விழித்து + எழும் புணர்ந்து விழித்தெழும் என அமைகிறது.
   **Source:** [2025 பாடநூல் உரை](https://www.scribd.com/document/1074941698/Class-6-Tamil-Tamil-Tamil-Term-3-2025-Edition-www-tntextbooks-in)
