# இயல் 3.2 — இளைய தோழனுக்கு

> **பாடநூல்:** ஆறாம் வகுப்பு தமிழ், Term 3, 2025 திருத்திய பதிப்பு  
> **மூலப் பக்கங்கள்:** பாடநூல் அச்சுப் பக்கங்கள் 47–48 (Repository PDF: [page_56.pdf](https://github.com/Eaglesiva/tn-class-06/blob/main/tamil/term3/iel_3/02_ilaiya_thozhanukku/page_56.pdf))

## கற்பவை கற்றபின்
1. ‘தன்னம்பிக்கை’ என்னும் தலைப்பில் கவிதை ஒன்றை எழுதி வகுப்பில் பகிர்க.
2. ‘நம்பிக்கையே வெற்றி’ என்பதை உணர்த்தும் கதை ஒன்றைத் தேடி எழுதி வருக.

## மதிப்பீடு — சரியான விடையைத் தேர்ந்தெடுத்து எழுதுக
1. உன்னுடன் நீயே ______ கொள்.
   - அ) சேர்ந்து
   - ஆ) பகை
   - இ) கைகுலுக்கிக்
   - ஈ) நட்பு

2. கவலைகள் ______ அல்ல.
   - அ) சுமைகள்
   - ஆ) சுவைகள்
   - இ) துன்பங்கள்
   - ஈ) கைக்குழந்தைகள்

3. ‘விழித்தெழும்’ என்னும் சொல்லைப் பிரித்து எழுதக் கிடைப்பது எது?
   - அ) விழி + எழும்
   - ஆ) விழித்து + எழும்
   - இ) விழி + தெழும்
   - ஈ) விழித் + தெழும்

4. ‘போவதில்லை’ என்னும் சொல்லைப் பிரித்து எழுதக் கிடைப்பது எது?
   - அ) போவது + இல்லை
   - ஆ) போ + இல்லை
   - இ) போவது + தில்லை
   - ஈ) போவது + தில்லை

5. ‘படுக்கையாகிறது’ என்னும் சொல்லைப் பிரித்து எழுதக் கிடைப்பது எது?
   - அ) படுக்கை + யாகிறது
   - ஆ) படுக்கையா + ஆகிறது
   - இ) படுக்கையா + கிறது
   - ஈ) படுக்கை + ஆகிறது

6. தூக்கி + கொண்டு என்பதனைச் சேர்த்தெழுதக் கிடைக்கும் சொல் எது?
   - அ) தூக்கிகொண்டு
   - ஆ) தூக்குக்கொண்டு
   - இ) தூக்கிக்கொண்டு
   - ஈ) தூக்குகொண்டு

7. விழித்து + எழும் என்பதனைச் சேர்த்தெழுதக் கிடைக்கும் சொல் எது?
   - அ) விழியெழும்
   - ஆ) விழித்தெழும்
   - இ) விழித்தழும்
   - ஈ) விழித்துஎழும்

## குறுவினா
1. கவலைகளைக் கவிஞர் எவ்வாறு உருவகப்படுத்துகிறார்?
2. தோல்வி எப்போது தூண்டுகோலாகும்?

## சிறுவினா
பூமி எப்போது பாதையாகும்?

## சிந்தனை வினா
வாழ்வில் உயர நம்பிக்கையைப் போன்று வேறு என்னென்ன பண்புகள் தேவை என்று நீங்கள் கருதுகிறீர்கள்?

**மூலக் குறிப்பு:** பாடநூலில் 4-ஆம் வினாவின் இ/ஈ விருப்பங்கள் ஒரேபோல் அச்சிடப்பட்டுள்ளன; கேள்வித்தாள் வடிவில் ஈ-விருப்பம் வேறுபடுத்தி வழங்கப்பட்டுள்ளது.
