# இயல் 1.2 — பாஞ்சை வளம் — Quiz

## STEP 2 — Original Textbook MCQ

1. ஊர்வலத்தின் முன்னால் எது அசைந்து வந்தது?
   - அ) தோரணம்
   - ஆ) வானரம்
   - இ) வாரணம்
   - ஈ) சந்தனம்
   **விடை:** இ
   **விளக்கம்:** வாரணம் என்பது யானையைக் குறிக்கும்; ஊர்வலத்தின் முன் யானை வந்தது.
   **Source:** [Tamil Vithai](https://www.tamilvithai.com/2026/01/6th-std-tamil-all-questions-answers-25_4.html)

2. பாஞ்சாலங்குறிச்சியில் எது நாயை விரட்டிடும்?
   - அ) முயல்
   - ஆ) நரி
   - இ) பரி
   - ஈ) புலி
   **விடை:** அ
   **விளக்கம்:** பாடலில் பாஞ்சாலங்குறிச்சியின் வீர வளத்தைச் சுட்ட முயல் நாயை விரட்டுவதாகக் கூறப்படுகிறது.
   **Source:** [Tamil Vithai](https://www.tamilvithai.com/2026/01/6th-std-tamil-all-questions-answers-25_4.html)

3. 'மெத்தை வீடு' என்று குறிப்பிடப்படுவது எது?
   - அ) மெத்தை விரிக்கப்பட்ட வீடு
   - ஆ) படுக்கையறை உள்ள வீடு
   - இ) மேட்டுப் பகுதியில் உள்ள வீடு
   - ஈ) மாடி வீடு
   **விடை:** ஈ
   **விளக்கம்:** பாடலின் பொருளுரையில் மெத்தை வீடு என்பது மதில்களால் சூழப்பட்ட மாடி வீடு என விளக்கப்படுகிறது.
   **Source:** [Tamil Vithai](https://www.tamilvithai.com/2026/01/6th-std-tamil-all-questions-answers-25_4.html)

4. 'பூட்டுங்கதவுகள்' என்னும் சொல்லைப் பிரித்து எழுதக் கிடைப்பது எது?
   - அ) பூட்டு + கதவுகள்
   - ஆ) பூட்டும் + கதவுகள்
   - இ) பூட்டின் + கதவுகள்
   - ஈ) பூட்டிய + கதவுகள்
   **விடை:** ஆ
   **விளக்கம்:** பூட்டுங்கதவுகள் = பூட்டும் + கதவுகள்.
   **Source:** [Tamil Vithai](https://www.tamilvithai.com/2026/01/6th-std-tamil-all-questions-answers-25_4.html)

5. 'தோரணமேடை' என்னும் சொல்லைப் பிரித்து எழுதக் கிடைப்பது எது?
   - அ) தோரணம் + மேடை
   - ஆ) தோரண + மேடை
   - இ) தோரணம் + ஒடை
   - ஈ) தோரணம் + ஓடை
   **விடை:** அ
   **விளக்கம்:** தோரணமேடை = தோரணம் + மேடை.
   **Source:** [Tamil Vithai](https://www.tamilvithai.com/2026/01/6th-std-tamil-all-questions-answers-25_4.html)

6. வாசல் + அலங்காரம் என்பதனைச் சேர்த்தெழுதக் கிடைக்கும் சொல் எது?
   - அ) வாசல்அலங்காரம்
   - ஆ) வாசலங்காரம்
   - இ) வாசலலங்காரம்
   - ஈ) வாசலிங்காரம்
   **விடை:** இ
   **விளக்கம்:** வாசல் + அலங்காரம் புணர்ந்து வாசலலங்காரம் என அமைகிறது.
   **Source:** [Tamil Vithai](https://www.tamilvithai.com/2026/01/6th-std-tamil-all-questions-answers-25_4.html)
