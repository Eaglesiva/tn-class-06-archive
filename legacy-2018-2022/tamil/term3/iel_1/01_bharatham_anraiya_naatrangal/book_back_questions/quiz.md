# இயல் 1.1 — பாரதம் அன்றைய நாற்றங்கால் — Quiz

## STEP 2 — Original Textbook MCQ

1. தேசம் உடுத்திய நூலாடை எனக் கவிஞர் குறிப்பிடும் நூல் எது?
   - அ) திருவாசகம்
   - ஆ) திருக்குறள்
   - இ) திரிகடுகம்
   - ஈ) திருப்பாவை
   **விடை:** ஆ
   **விளக்கம்:** பாடலில் திருக்குறள் நாட்டின் நூலாடையாக உருவகிக்கப்படுகிறது.
   **Source:** [Athiyaman Team](https://athiyamanteam.com/recent-post/6th-tamil-new-book-term-3-bharatham-andraiya-natrankal/)

2. காளிதாசனின் தேனிசைப் பாடல்கள் எதிரொலிக்கும் இடம் எது?
   - அ) காவிரிக்கரை
   - ஆ) வைகைக்கரை
   - இ) கங்கைக்கரை
   - ஈ) யமுனைக்கரை
   **விடை:** அ
   **விளக்கம்:** பாடல் காளிதாசனின் பாடல்கள் காவிரிக்கரையில் எதிரொலிப்பதாகக் கூறுகிறது.
   **Source:** [Athiyaman Team](https://athiyamanteam.com/recent-post/6th-tamil-new-book-term-3-bharatham-andraiya-natrankal/)

3. கலைக்கூடமாகக் காட்சி தருவது எது?
   - அ) சிற்பக்கூடம்
   - ஆ) ஓவியக்கூடம்
   - இ) பள்ளிக்கூடம்
   - ஈ) சிறைக்கூடம்
   **விடை:** அ
   **விளக்கம்:** கல்லில் செதுக்கிய சிற்பங்கள் கலைக்கூடமாகக் காட்சியளிக்கின்றன.
   **Source:** [Athiyaman Team](https://athiyamanteam.com/recent-post/6th-tamil-new-book-term-3-bharatham-andraiya-natrankal/)

4. 'நூலாடை' என்னும் சொல்லைப் பிரித்து எழுதக் கிடைப்பது எது?
   - அ) நூல் + ஆடை
   - ஆ) நூலா + டை
   - இ) நூல் + லாடை
   - ஈ) நூலா + ஆடை
   **விடை:** அ
   **விளக்கம்:** நூலாடை = நூல் + ஆடை.
   **Source:** [Athiyaman Team](https://athiyamanteam.com/recent-post/6th-tamil-new-book-term-3-bharatham-andraiya-natrankal/)

5. எதிர் + ஒலிக்க என்பதனைச் சேர்த்தெழுதக் கிடைக்கும் சொல் எது?
   - அ) எதிரலிக்க
   - ஆ) எதிர்ஒலிக்க
   - இ) எதிரொலிக்க
   - ஈ) எதிர்ரொலிக்க
   **விடை:** இ
   **விளக்கம்:** எதிர் + ஒலிக்க புணர்ந்து எதிரொலிக்க என அமைகிறது.
   **Source:** [Athiyaman Team](https://athiyamanteam.com/recent-post/6th-tamil-new-book-term-3-bharatham-andraiya-natrankal/)
