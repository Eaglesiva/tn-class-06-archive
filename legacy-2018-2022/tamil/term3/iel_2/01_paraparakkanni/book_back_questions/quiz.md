# இயல் 2.1 — பராபரக் கண்ணி — Quiz

## STEP 2 — Original Textbook MCQ

1. தம் + உயிர் என்பதனைச் சேர்த்து எழுதக் கிடைக்கும் சொல் எது?
   - அ) தம்முயிர்
   - ஆ) தமதுயிர்
   - இ) தம்உயிர்
   - ஈ) தம்முஉயிர்
   **விடை:** இ
   **விளக்கம்:** 2025 பாடநூல் பாடல்வரியில் ‘தம்உயிர்போல்’ என இடைவெளியின்றி, கூடுதல் மெய் இரட்டிப்பு இல்லாமல் உள்ளது.
   **Source:** [2025 பாடநூல் உரை](https://www.scribd.com/document/1074941698/Class-6-Tamil-Tamil-Tamil-Term-3-2025-Edition-www-tntextbooks-in)

2. இன்புற்று + இருக்க என்பதனைச் சேர்த்து எழுதக் கிடைக்கும் சொல் எது?
   - அ) இன்புற்றிருக்க
   - ஆ) இன்புறுறிருக்க
   - இ) இன்புற்றுஇருக்க
   - ஈ) இன்புறுஇருக்க
   **விடை:** அ
   **விளக்கம்:** இன்புற்று + இருக்க = இன்புற்றிருக்க.
   **Source:** [2025 பாடநூல் உரை](https://www.scribd.com/document/1074941698/Class-6-Tamil-Tamil-Tamil-Term-3-2025-Edition-www-tntextbooks-in)

3. ‘தானென்று’ என்னும் சொல்லைப் பிரித்து எழுதக் கிடைப்பது எது?
   - அ) தானெ + என்று
   - ஆ) தான் + என்று
   - இ) தா + னென்று
   - ஈ) தான் + னென்று
   **விடை:** ஆ
   **விளக்கம்:** தானென்று = தான் + என்று.
   **Source:** [2025 பாடநூல் உரை](https://www.scribd.com/document/1074941698/Class-6-Tamil-Tamil-Tamil-Term-3-2025-Edition-www-tntextbooks-in)

4. ‘சோம்பல்’ என்னும் சொல்லுக்குப் பொருத்தமான எதிர்ச்சொல் எது?
   - அ) அழிவு
   - ஆ) துன்பம்
   - இ) சுறுசுறுப்பு
   - ஈ) சோகம்
   **விடை:** இ
   **விளக்கம்:** சோம்பலுக்கு எதிரான சொல் சுறுசுறுப்பு.
   **Source:** [2025 பாடநூல் உரை](https://www.scribd.com/document/1074941698/Class-6-Tamil-Tamil-Tamil-Term-3-2025-Edition-www-tntextbooks-in)
