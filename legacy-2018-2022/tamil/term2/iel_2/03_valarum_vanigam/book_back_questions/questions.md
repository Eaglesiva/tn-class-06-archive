# இயல் 2.3 — வளரும் வணிகம்

ஆதாரம்: [2025 SCERT ஆறாம் வகுப்பு தமிழ் — இரண்டாம் பருவம்](https://huggingface.co/datasets/Joemn/TamilNadu-State-board-books-2025-Tamil-and-english-versions/blob/main/6th-standard/Tamil/Class_6_Tamil_Tamil_Tamil_-_Term_2_-_2025_Edition.md)

## மதிப்பீடு — சரியான விடையைத் தேர்ந்தெடுத்து எழுதுக
1. வீட்டுப் பயன்பாட்டிற்காகப் பொருள் வாங்குபவர் யார்?
   - அ) நுகர்வோர்
   - ஆ) தொழிலாளி
   - இ) முதலீட்டாளர்
   - ஈ) நெசவாளர்

2. வணிகம் + சாத்து என்பதனைச் சேர்த்தெழுதக் கிடைக்கும் சொல் எது?
   - அ) வணிகசாத்து
   - ஆ) வணிகம்சாத்து
   - இ) வணிகச்சாத்து
   - ஈ) வணிகத்துசாத்து

3. பண்டம் + மாற்று என்பதனைச் சேர்த்தெழுதக் கிடைக்கும் சொல் எது?
   - அ) பண்டமாற்று
   - ஆ) பண்டம்மாற்று
   - இ) பண்மாற்று
   - ஈ) பண்டுமாற்று

4. மின்னணு என்னும் சொல்லைப் பிரித்து எழுதக் கிடைப்பது எது?
   - அ) மின் + னணு
   - ஆ) மின்ன + அணு
   - இ) மின்னல் + அணு
   - ஈ) மின் + அணு

5. விரிவடைந்த என்னும் சொல்லைப் பிரித்து எழுதக் கிடைப்பது எது?
   - அ) விரி + வடைந்த
   - ஆ) விரி + அடைந்த
   - இ) விரிவு + அடைந்த
   - ஈ) விரிவ் + அடைந்த

## குறுவினா
1. வணிகம் என்றால் என்ன?
2. பண்டமாற்று முறைக்கு எடுத்துக்காட்டுத் தருக.
3. சிறுவணிகப் பொருள்கள் யாவை?

## சிறுவினா
1. சிறுவணிகம், பெருவணிகம் வேறுபடுத்துக.
2. பழந்தமிழர் ஏற்றுமதி, இறக்குமதி செய்த பொருள்கள் எவை?
