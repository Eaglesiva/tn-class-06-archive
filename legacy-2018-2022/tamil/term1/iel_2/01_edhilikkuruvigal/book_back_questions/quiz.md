# 6-ஆம் வகுப்பு தமிழ் — பருவம் 1 — இயல் 2.1 — ஏதிலிக்குருவிகள் — Quiz

## STEP 2 — Original Textbook MCQ

### 1. கூடு கட்டுவதற்கு மரம் கிடைக்காத பறவைகள் ______ வேறிடம் சென்றன.
- (அ) பதிலிகளாக
- (ஆ) ஏதிலிகளாக
- (இ) விருந்தாளிகளாக
- (ஈ) பயணிகளாக

**விடை:** (ஆ)  
**விளக்கம்:** மரங்கள் இல்லாததால் பறவைகள் தங்களின் வாழிடத்தை இழந்து ஏதிலிகளாக வேறிடத்திற்குச் சென்றன.  
**Source:** [FreeTNBooks Answer Guide](https://www.freetnbooks.com/6th-std-tamil-guide-term-1-lesson-2-1-new/)

### 2. 'முன்பென்றால்' என்னும் சொல்லைப் பிரித்து எழுதக் கிடைப்பது ______.
- (அ) முன் + பென்றால்
- (ஆ) முன்பு + அன்றால்
- (இ) முன்பு + என்றால்
- (ஈ) முன்பு + பென்றால்

**விடை:** (இ)  
**விளக்கம்:** 'முன்பென்றால்' என்பது 'முன்பு + என்றால்' எனப் பிரிகிறது.  
**Source:** [FreeTNBooks Answer Guide](https://www.freetnbooks.com/6th-std-tamil-guide-term-1-lesson-2-1-new/)

### 3. 'சுழித்தோடும்' என்னும் சொல்லைப் பிரித்து எழுதக் கிடைப்பது ______.
- (அ) சுழித்து + ஓடும்
- (ஆ) சுழி + தோடும்
- (இ) சுழி + ஓடும்
- (ஈ) சுழித் + தோடும்

**விடை:** (அ)  
**விளக்கம்:** பாடநூலில் உள்ள சொல் 'சுழித்தோடும்'; சரியான பிரிப்பு 'சுழித்து + ஓடும்'.  
**Source:** [FreeTNBooks Answer Guide](https://www.freetnbooks.com/6th-std-tamil-guide-term-1-lesson-2-1-new/)

### 4. வழி + எல்லாம் என்பதனைச் சேர்த்தெழுதக் கிடைக்கும் சொல் ______.
- (அ) வழிஎல்லாம்
- (ஆ) வழியிலெல்லாம்
- (இ) வழில்லாம்
- (ஈ) வழியெல்லாம்

**விடை:** (ஈ)  
**விளக்கம்:** 'வழி + எல்லாம்' புணர்ந்து 'வழியெல்லாம்' என அமைகிறது.  
**Source:** [FreeTNBooks Answer Guide](https://www.freetnbooks.com/6th-std-tamil-guide-term-1-lesson-2-1-new/)
