# இயல் 3.2 — துன்பத்தை வெல்லும் கல்வி — விடைக் குறிப்புகள் (STEP 1)

### சரியான விடைகள்
1. (ஆ) தூற்றும்படி.
2. (இ) மூத்தோர்.
3. (இ) கை + பொருள்.
4. (ஆ) மானமில்லா.

### சொற்றொடரில் அமைத்து எழுதுக
மாணவர் தாமாகச் சொற்றொடர் அமைக்க வேண்டிய பயிற்சி; மாதிரி விடைகள் இங்கு கட்டாயப்படுத்தப்படவில்லை.

### குறுவினா — மாணவர் பதிலுக்கான இடம்
1. நாம் யாருடன் சேரக்கூடாது? விடை:
2. எதை நம்பி வாழக்கூடாது? விடை:
3. இந்தப் பாடலின் முதல் இரு வரிகள் நினைவூட்டும் திருக்குறள் எது? விடை:
4. நாம் எவ்வாறு வாழ்ந்தால் பெருமை பெறலாம்? விடை:

### சிறுவினா — மாணவர் பதிலுக்கான இடம்
1. நாம் யார் தூற்றும்படி வாழக்கூடாது? விடை:
2. நாம் எதனை மறக்கக்கூடாது? விடை:
3. எளிய தமிழில் சமூகச் சீர்திருத்தக் கருத்துகளை வலியுறுத்திப் பாடியவர் யார்? விடை:
4. திரையிசைப் பாடல்களில் உழைப்பாளிகளின் உயர்வைப் போற்றியவர் யார்? விடை:
5. பட்டுக்கோட்டை கல்யாணசுந்தரனாரின் சிறப்புப்பெயர் யாது? விடை:
