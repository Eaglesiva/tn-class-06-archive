# இயல் 3.3 — கல்விக்கண் திறந்தவர் — Quiz

## STEP 2 — Original textbook MCQ
1. ஆடு மேய்க்கும் சிறுவர்கள் பள்ளிக்குச் செல்லாத காரணம் — ஊரில் பள்ளிக்கூடம் இல்லை.
2. பசியின்றி = பசி + இன்றி.
3. படிப்பறிவு = படிப்பு + அறிவு.
4. காடு + ஆறு = காட்டாறு.

## STEP 3 — Transformed one-mark questions
1. குழந்தைகள் ஏற்றத்தாழ்வின்றிப் படிக்க அறிமுகப்படுத்தப்பட்ட திட்டம் — சீருடைத் திட்டம்.
2. காமராசரைக் கல்விக்கண் திறந்தவர் எனப் பாராட்டியவர் — தந்தை பெரியார்.

QA: Step 2 = 4; Step 3 = 2; மொத்தம் 6. குறுவினா/சிறுவினா Quiz-ஆக மாற்றப்படவில்லை.
